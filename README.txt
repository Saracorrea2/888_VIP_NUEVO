888 VIP POS - VERSION MEJORADA

Esta versión está preparada para trabajar con la estructura de base de datos que ya trae el proyecto.

IMPORTANTE:
- NO ejecutar ningún SQL de migración.
- NO importar un SQL para instalar las mejoras.
- Hacer una copia de seguridad de la carpeta y de la base de datos antes de reemplazar archivos.
- La versión no incluye conexión con Bold.

MEJORAS:
- Historial de auditoría con usuario, fecha, módulo, acción y datos.
- Historial de inventario: entradas, salidas y ajustes con stock anterior/nuevo.
- Precio editable por línea de venta sin cambiar el precio del catálogo.
- Valor final editable al cerrar una cuenta, con motivo y registro del ajuste.
- El cierre de venta descuenta stock una sola vez y registra el movimiento.
- Gastos de inventario aumentan automáticamente el stock y dejan movimiento.
- Las mesas se liberan y recuperan su nombre Mesa X al cerrar.
- Reportes permiten abrir una venta y ver productos, cantidades, precios y ajuste.
- Colores renovados en azul oscuro y verde/teal.
