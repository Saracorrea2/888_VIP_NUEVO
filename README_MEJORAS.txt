888 VIP POS - MEJORAS Y CORRECCION

Esta version conserva la base del proyecto y NO elimina registros.

Correcciones solicitadas:
- Inicio vuelve a mostrar ventas de hoy y ventas separadas por medio de pago.
- En Inicio, cada medio de pago se puede abrir en Reportes.
- Reportes > Ventas por medio de pago incluye boton "Ver ventas".
- Al elegir un medio se listan sus ventas del dia.
- Cada venta tiene "Abrir venta" y muestra los productos, cantidades, precios y total.
- La tabla general de ventas mantiene "Ver venta".

IMPORTANTE:
1. Haz copia de seguridad de tu base de datos antes de reemplazar archivos.
2. Copia los archivos PHP del ZIP sobre tu carpeta del proyecto, conservando tu conexion.php y datos.
3. No importes el 888_vip.sql encima de una base con datos.
4. Si la caja es obligatoria en ventas, abre una caja en Caja antes de cobrar.
